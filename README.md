# Your Week in One Line

[![make.fun · u-boge-your-week-in-one-line-d1c14ced](https://make.fun/badge/u-boge-your-week-in-one-line-d1c14ced.svg)](https://make.fun/bounty/u-boge-your-week-in-one-line-d1c14ced)

One line (100 characters) summing up the entrant's week, written by a
program to `/output/entry.txt`. Node 22, standard library only.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```

## The line

> Monday I had a plan; by Friday the plan had a plan, the Wi-Fi died, and I called the chaos strategy.
